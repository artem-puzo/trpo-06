# ПР №6 — PHP: файлы, JSON, сессии, подготовка к MVC

Менеджер заметок: заметки в JSON, имя пользователя в сессии,
обработчик отделён от шаблонов.

## Требования и запуск
PHP 8.1+, зависимостей нет.

    php -S localhost:8000 -t public

Открыть http://localhost:8000/index.php

## Структура
- public/index.php — точка входа, обработка запроса, маршрут по ?page=
- src/storage.php — чтение и запись JSON
- src/session.php — сессия
- src/view.php — render() и e()
- templates/ — HTML-шаблоны
- data/dataset/ — notes.json, users.json, session_scenarios.json

## Использование dataset
- notes.json — список заметок, сюда пишет форма
- users.json — известные пользователи на странице сценариев
- session_scenarios.json — таблица сценариев проверки сессии

## Файловое хранилище
Чтение: json_decode с JSON_THROW_ON_ERROR. Запись: LOCK_EX.
id новой записи = максимальный id + 1.
Отсутствующий или повреждённый файл даёт сообщение, а не fatal error.

## Сессия
$_SESSION['display_name'], по умолчанию «Гость». Установка и очистка
через POST с redirect.

## Разделение обработчика и шаблона
index.php готовит данные и вызывает render(). Шаблон только выводит HTML.

## Ограничения
- нет авторизации и защиты от CSRF
- JSON читается целиком, при росте данных это медленно
- при одновременной записи возможны потери данных
- маршрутизация через ?page= примитивна, дальше нужен MVC

## Проверка после клонирования
1. Запустить сервер, открыть сайт: «Гость», две заметки.
2. Сохранить имя, обновить страницу: имя осталось. Очистить: «Гость».
3. Добавить заметку: появилась в notes.json, F5 не дублирует.
4. Пустое название: сообщение об ошибке.
5. ?page=abc: 404.
